# Flexpa Documentation

> Flexpa is a healthcare data platform providing patient-consented health insurance claims, plan details, and medical records through FHIR R4 compliant APIs. The platform consists of Flexpa Link (a secure consent SDK), Flexpa API (FHIR-based REST API), and access to the largest network of payer FHIR endpoints in the US.

## Core Concepts

Flexpa operates through three main components:

- **Network**: The largest directory of payer FHIR endpoints in the US, providing access to health plans and insurers
- **Consent (Flexpa Link)**: A secure, embeddable SDK for obtaining patient consent to access their health data
- **Records (Flexpa API)**: A FHIR R4 compliant REST API for retrieving standardized health insurance claims and medical records

The typical integration flow: Patient consents via Flexpa Link → Exchange public token for access token → Query FHIR API for health records.

## Code Examples

### Start OAuth Flow
```typescript
import FlexpaClient from '@flexpa/node-sdk';

// Client-side (browser) example
(async () => {
  const codeVerifier = await FlexpaClient.generateCodeVerifier();
  const codeChallenge = await FlexpaClient.generateCodeChallenge(codeVerifier);

  const authUrl = FlexpaClient.buildAuthorizationUrl({
    publishableKey: 'pk_test_...',
    redirectUri: 'https://yourapp.com/callback',
    codeChallenge,
    externalId: 'user-123',
  });

  window.location.href = authUrl;
})();
```

### Exchange Code for Token
```typescript
// Server-side example (e.g., in your callback handler)
const client = await FlexpaClient.fromAuthorizationCode(
  code,
  codeVerifier,
  redirectUri,
  publishableKey
);

const accessToken = client.getAccessToken();
```

### Fetch Patient Data
```typescript
const client = FlexpaClient.fromBearerToken(accessToken);
const everything = await client.$everything();
const claims = await client.search('ExplanationOfBenefit');
```

### Extract Data with ViewDefinition
```typescript
const response = await fetch('https://api.flexpa.com/fhir/ViewDefinition/$run', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${accessToken}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    resourceType: 'Parameters',
    parameter: [{ name: 'viewResource', resource: viewDefinition }]
  })
});
```
